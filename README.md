# Audioguía de estudio: Escoltas de Bandera de Coahuila 2026–2027

Sitio de estudio con audioguía por tema, rutina, tarjetas y examen.

## Usar sin conexión

1. Abre el sitio publicado mientras tengas internet y espera a que aparezca **Copia sin conexión preparada**.
2. Si el navegador ofrece **Instalar en este dispositivo**, úsalo para tener un acceso directo.
3. Después puedes volver a abrir la guía sin internet. El avance se guarda en ese mismo dispositivo y navegador.

La voz depende de las voces en español instaladas en el dispositivo; algunas voces del sistema podrían requerir internet.

Sitio: https://gerardocruzr.github.io/audioguia-escoltas-coahuila/
